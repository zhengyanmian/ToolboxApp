# ToolboxApp 工具箱

原创安卓工具箱 App（React Native 0.88 + TypeScript，Hermes），收录日常高频小工具。全部代码原创、所有功能免费无限制、无需登录、数据不出本机。

## v2.0 按 ColorOS 17「流体设计」重构

- **纯色底 + 灰阶层级**：移除背景渐变与彩色光晕，深色纯黑、浅色近白，通透感靠留白与灰阶而不是背景光斑。
- **凝光跟手**：按在任何按钮 / 胶囊 / 圆钮 / 卡片 / 磁贴上的那一点会扩散一团柔光（150ms 扩开、340ms 消退，消退后节点自动卸载）。
- **柔性反馈**：按下 spring 压到 0.958，松手 speed 15 / bounciness 9 弹回，带惯性回弹。
- **圆形返回按钮 + 悬浮标题**：不再把返回键和标题塞进同一条长条。
- **主题切换从按钮那一角扩开**：以触发按钮为圆心的实心圆扩满全屏，盖满的同一帧换色，整屏不再闪。
- **页面转场**：首页淡出的同时工具页滑入，返回时首页缩放淡入（不再是硬切）。
- **计算器**：全屏圆键 + 「按下/滑过只给光效与震动，松手才输入」（滑动选键），与 ColorOS 计算器一致。
- **尺子**：进入即锁横屏，刻度贴着屏幕长边，校准入口固定在右下角。
- **指南针 / 水平仪**：指南针先给磁力计近似航向（不再等两个传感器而空白几秒）；水平仪加 ±1.2° 软死区，平放时气泡真正落在中心。
- **光棱坦克**：改成 prism.uyanide.com 的功能结构——单画布 + 阈值 + 对比度 + 像素处理方式 + 扩散迭代 + 存 PNG。

## 界面与视觉（v2.0 流体设计）

- **深色 / 亮色双主题**：`src/theme.tsx` 提供两套调色板。首页右上角按钮**点按**在深/浅色之间切换，**长按**恢复「跟随系统」，选择持久化到本机。切换时有一层同色蒙版淡入淡出（约 400ms），不会硬闪一下。
- **「凝光」材质**：`GlassLayer` 只用**一条连续三段渐变 + 一道发丝级顶边高光**做表面，不再用上下两个色块拼接（那样会在按钮正中留下一条可见的分界线）。全项目已移除 `elevation` / `shadowColor`——Android 上带透明背景的 elevation 会渲染成一块方形阴影。
- **统一设计系统**：`src/ui.tsx` 提供 `Page / Card / Btn / Chip / Segmented / Field / DateField / DatePickerSheet / Slider / Toggle / Result / KV / IconTile / RoundButton / Glow / Tap / SettingRow / GlassLayer` 等组件，所有工具页面共用同一套圆角、间距、描边。
- **日期一律用选择器**：`DateField` 点一下弹出月历 + 时间步进面板（`mode: date / time / datetime`），不再让用户一个字符一个字符地敲日期。
- **零 emoji**：界面图标全部为内置矢量线性图标（`src/icons.tsx`，24×24 网格、圆头描边），首页磁贴按分类配色渐变。
- **主题切换实时生效**：工具页样式通过 `dynStyles((C) => StyleSheet.create({...}))` 延迟求值，模块级样式也会跟随主题。
- **导航**：工具页只保留左上角返回键与系统返回键（不做侧滑返回手势，避免误触）。

## v1.9 修复与改进（第二轮真机反馈）

- **指尖转重做**：只用 `pageX/pageY` 换算到舞台坐标，**框外的手指一律不计、不显示**；「开抽」按钮的触摸也在同一套触摸流里判定（不再被多指手势抢走），所以按着一堆手指也能点得动；支持**一起松手自动开抽**（可关）；抬起后位置保留，随时「再抽一次」；不再出现「没抬起却提示已抬起」。
- **计算器重做**：全屏圆键布局（AC / % / 退格 / ÷ × − + / 00 / = ），`=` 用淡紫色实心圆；补上括号、π、e、阶乘、开方、ln、1/x、sin/cos/tan（DEG/RAD 切换）、历史记录；圆键尺寸同时受屏宽与屏高约束，展开科学键也不会顶出屏幕。
- **振动器重做**：开始/停止合并成同一颗按钮；删掉没用的节奏文本框（原来它还会把下方内容顶下去）；节奏预览改成整段条带，改次数时脉冲密度真的会变；预设节奏点一下开始、再点一下停止，不用再滑回顶部。
- **金属探测仪**：探到金属时「哒哒哒」连击震动（信号越强连击越密、频率越高），可调灵敏度与震动开关。
- **指南针 / 水平仪**：全部改设计系统语义色，表盘 / 气泡改用 SVG 绘制，修掉圆形面板上方与左侧露出的白边。
- **噪音检测**：进页面直接开始测量，没有开始/停止按钮；读数做指数平滑（保留 1 位小数），不再一直闪。
- **尺子**：刻度贴屏幕边缘绘制（0 刻度就在边缘上），手指在尺身上滑动拖出读数线；校准入口是右下角一颗按钮，点开选择参照物（银行卡 / A4）或直接输入实测毫米数；删掉重复的按钮。
- **IP 查询**：加自定义 IP / 域名输入框（之前承诺的功能），结果含位置、运营商、ASN、时区、经纬度。
- **NCM 转换**：转换完成后可直接「用其他应用打开」或「打开所在文件夹」，跳系统文件管理器（多级降级），不用再复制路径。
- **屏幕时钟**：工具条改用凝光玻璃；新增底色深/浅切换与自定义 HEX 字色，预设色增加到 8 个。
- **日期输入**：年龄计算、纪念日、日期计算、农历、时间计算器、时间戳六个工具全部换成日期选择器。

## v1.8.1 修复与改进（真机反馈）

- **修复动画崩溃**：真机上部分页面会报 `Attempting to run JS driven animation on animated node that has been moved to 'native'` 并跳回首页。原因是同一个 Animated 节点混用了 native 驱动与 JS 驱动。反应力测试背景色改为普通 state、白色闪层独立驱动；`Toggle` 的颜色插值拆到内层独立节点。同时反应力测试变绿等待时间缩短，抬手判定不再有延迟。
- **修复 PNG 自检**：`pako` 在 Hermes 下 `default` 导出为空，改为命名导入 + 多候选兜底，运行自检的「PNG 编解码」恢复正常，失败时给中文可读错误。
- **决定转盘**：指针与结果的数学改为「先随机定扇区 → 反解落点角度 → 用真实落点反算索引」，保证指针指哪个就出哪个（原实现多加了半个扇区，约一半情况下对不上）；指针与轴心改为绝对定位居中，圆心不再偏移；扇区文字沿半径排布并按底色亮度自动取黑/白。
- **指尖转**：修复「按住手指后点开抽没反应」——系统把手指的触摸事件 cancel 掉后圆点集合被清空，按钮取不到手指。现在松手后位置保留 10 秒，期间同样可以开抽；去掉常驻闪烁，圆点改为带序号的弹入。
- **时间计算器 / 时间戳**：改为输入即算，日期敲 8 位数字自动补成 `2026-10-16`、时间敲 4 位自动补成 `08:30`，每行有「现在」快捷与一键清空，结果实时更新。
- **工作性价比**：重做为「输入即算 + 人话结论」，给出表面时薪（税前/到手）、含通勤的真实时薪、摸鱼时薪、时薪缩水比例、月真实投入时长与年化收入，并用奶茶/电影票/手机换算成工作时长。
- **手持弹幕**：按钮改为 ColorOS 风格玻璃材质；进页面即所见即所得预览；设置面板改底部玻璃抽屉，支持实时调速调字号、文案预设、一键清空、横屏大字开关；底部手势提示条可关闭。
- **屏幕时钟**：秒数与主数字改用同一条基线对齐，秒字号放大也不再错位；屏幕方向切换按钮换成更达意的图标。
- **外观模式**：移除首页底部冗余的「外观模式」卡片，统一由右上角按钮（点按切换 / 长按跟随系统）。
- **移除侧滑返回**：真机上体验不佳（易误触），已彻底删除。

## 自研原生模块（android/app/src/main/java/com/toolboxapp/）

`ToolboxNative` 一个模块覆盖全部原生能力，全部 try/catch 防御：屏幕常亮、横竖屏切换、沉浸式全屏、磁力计、加速度计、指南针（融合解算航向）、振动（波形节奏）、噪音检测（MediaRecorder 振幅）、当前壁纸导出、设备 Build 信息、复制到剪贴板、把文件写入系统「下载」目录（Android 10+ 走 MediaStore，无需存储权限）。

## 特性

- 挖孔屏/状态栏安全区适配（react-native-safe-area-context），首页返回后保持滚动位置
- 安卓返回键正确导航（工具页返回回首页）
- 每个工具页顶部内置用途与操作说明
- 关键数据本地持久化（AsyncStorage）：主题模式、纪念日、计分板、番茄钟计数、尺子校准系数、历史今天缓存
- 全局错误边界：单页异常时显示可读错误信息与「返回首页」，不会闪退
- 添加新工具：在 `src/tools/` 写组件 → `src/registry.tsx` 注册（含图标名与分类）→ `src/details.ts` 加说明，三步完成
